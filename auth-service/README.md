## Descrição

Repositório inicial do framework [Nest](https://github.com/nestjs/nest) configurado com TypeScript.

## Configuração do projeto

```bash
$ npm install
```

## Compilação e execução do projeto

```bash
# desenvolvimento (development)
$ npm run start

# modo de observação (watch mode)
$ npm run start:dev

# modo de produção (production mode)
$ npm run start:prod
```

## Executando testes

```bash
# testes unitários
$ npm run test

# testes e2e (ponta a ponta)
$ npm run test:e2e

# cobertura de testes
$ npm run test:cov
```

## Implantação (Deploy)

Quando você estiver pronto para implantar sua aplicação NestJS em produção, existem algumas etapas cruciais que você pode seguir para garantir que ela funcione da maneira mais eficiente possível. Consulte a [documentação de deploy do NestJS](https://docs.nestjs.com/deployment) para obter mais informações.

Se você está procurando uma plataforma em nuvem para implantar sua aplicação NestJS, conheça o [Mau](https://mau.nestjs.com), nossa plataforma oficial para implantação de aplicações NestJS na AWS. O Mau torna o deploy simples e rápido, exigindo apenas alguns passos básicos:

```bash
$ npm install -g @nestjs/mau
$ mau deploy
```

Com o Mau, você pode implantar sua aplicação com apenas alguns cliques, permitindo que você se concentre na criação de funcionalidades em vez de gerenciar infraestrutura.

## Recursos Úteis

Confira alguns recursos que podem ser de grande ajuda ao trabalhar com o NestJS:

- Visite a [Documentação Oficial do NestJS](https://docs.nestjs.com) para aprender mais sobre o framework.
- Para dúvidas e suporte comunitário, acesse nosso [canal do Discord](https://discord.gg/G7Qnnhy).
- Para se aprofundar e obter experiência prática, confira nossos [cursos em vídeo oficiais](https://courses.nestjs.com/).
- Implante sua aplicação na AWS com a ajuda do [NestJS Mau](https://mau.nestjs.com) com poucos cliques.
- Visualize o grafo da sua aplicação e interaja com ela em tempo real utilizando o [NestJS Devtools](https://devtools.nestjs.com).
- Precisa de ajuda com o seu projeto (dedicação parcial ou integral)? Conheça o nosso [suporte corporativo oficial](https://enterprise.nestjs.com).
- Para ficar por dentro das novidades e atualizações, siga-nos no [X (antigo Twitter)](https://x.com/nestframework) e no [LinkedIn](https://linkedin.com/company/nestjs).
- Procurando uma oportunidade de trabalho ou quer anunciar uma vaga? Acesse nosso [portal oficial de vagas (Jobs board)](https://jobs.nestjs.com).
